## Hoe gebruik je dit

- **Bij start van een nieuwe sessie:** lees minstens dit README + `05-open-vragen-beslissingen.md`
  om te weten waar we staan.
- **Bij een strategische beslissing:** werk het relevante bestand bij én log de beslissing
  in `05-open-vragen-beslissingen.md`.
- **Houd het modulair:** elk onderwerp hoort in zijn eigen bestand. Niet alles in één dump.
- Elk bestand opent met een vaste kop: bron · datum laatst bijgewerkt · status.

## Kern in 3 zinnen (TL;DR)

1. De onderneming bouwt **custom leerplatformen** (video + AI-mentor/RAG + examens + kennisbank) op Next.js + Supabase.
2. Strategische focus: **externe opleiding** (klanten/partners/dealers + expert-academies), **niet** interne employee onboarding.
3. **Core** = partner/klant-educatie voor bedrijven met dealer-/installateursnetwerken; **wedge** (snelle cash) = expert-academies via de bestaande cases (HTP2.0, CoachedBy).
